# 🦷 Cabinet Dentaire Fès

[![Live Demo](https://img.shields.io/badge/Website-Live_Demo-brightgreen.svg?style=for-the-badge)](https://abdelghanirh.github.io/cabinet-dentaire-fes/)

A modern, responsive, and patient-focused website designed for Cabinet Dentaire Fès. Built to establish trust, showcase clinical work and treatment results, display verified patient reviews, and streamline appointment reservations.

---

## 🌟 Key Features

* 📸 **Smile & Treatment Gallery**: Interactive visual showcase displaying real patient transformations and treatment results.
* 📅 **Online Reservation System**: Integrated booking flow allowing patients to schedule consultations and appointments effortlessly.
* 📍 **Google Maps Integration**: Embedded interactive location map providing one-click directions directly to the clinic.
* ⭐ **Google Reviews Showcase**: Live ratings and patient feedback integrated directly from the clinic's Google Business Profile.
* 📱 **Fully Responsive Design**: Optimized for smooth performance across mobile phones, tablets, and desktop computers.

## ⚙️ Configuration & Customization

1. **Google Maps**:
   * Update the map `<iframe>` src URL in `index.html` with Cabinet Dentaire Fès's exact Google Maps location link.
2. **Online Booking**:
   * Link the preferred appointment booking handler or scheduling service within the reservation section.
3. **Google Reviews**:
   * Configure the Google Place ID to keep real-time patient ratings and reviews synchronized.
